Principles

Why the set feels
like one hand.

24px grid

Every icon lives on the same 24 × 24 canvas, so it drops into any 4 pt or 8 pt layout.

2px padding

The live area stays inside 2–22. Icons never touch their bounding box, so rows breathe.

1.5px stroke

The default weight pairs with text from 13 to 18 px. Change the token and the whole set follows.

4keylines

Circle, square, portrait and landscape keylines balance optical weight between shapes.
