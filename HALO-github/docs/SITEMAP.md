# HALO — Site Map

> **HALO** — one studio for **Design Systems**, **Icons** and **Type**.
> The motif: an eclipse. A dark object, a ring of light around it, the halo. Every page is "night with one light".

## Content tone
Short, confident, a little poetic: "Night with one light." Product claims stay concrete
(tints from a curve, a 24px keyline, a 1.25 type ratio).
